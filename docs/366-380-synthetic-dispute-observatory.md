# 대집단 2 — 합성 분쟁 관측·위험통제 (#366~#380)

#365의 불변 포트폴리오 manifest를 입력으로 사용해 projection, cohort, 통화별 exposure, aging, deadline risk, 집중도, 중복 군집, 증거 완전성, 역할 독립성, 재무상한, 이상징후, 읽기 전용 alert docket, snapshot 및 위험통제 보고서를 하나의 digest 계보로 결속한다.
