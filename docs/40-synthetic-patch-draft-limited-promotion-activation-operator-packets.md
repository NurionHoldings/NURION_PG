# 기능 #040 — 합성 제한승격 활성화 운영자 판단 패킷

## 목적

기능 #039에서 에테르니언 최종심사를 통과한 활성화 Manifest와 현재 거버넌스
차단조건을 하나의 불변 패킷으로 묶는다. 운영자가 정확히 같은 후보·평가군·관찰창·
관찰결과·rollback 조건을 판단할 수 있도록 하는 검토자료이며 승인이나 활성화가 아니다.

## 입력과 고정 범위

- 입력 상태는 `READY_FOR_SYNTHETIC_LIMITED_PROMOTION_OPERATOR_DECISION`만 허용한다.
- Manifest와 최종심사, 재확인 수신증·패킷, 계획·Shadow 계보의 다이제스트를 고정한다.
- 현재 거버넌스 다이제스트가 Manifest 작성 당시 값과 다르면 실패 폐쇄한다.
- 합성 표본 수, 관찰창, 관찰결과 및 rollback 조건을 그대로 보존한다.
- 패킷 유효기간은 생성 시점부터 24시간이며 자동 갱신하지 않는다.

## 권한 경계

ARKAON은 판단 패킷을 만들 수 있지만 운영자의 결정을 생성·추정·기록하지 않는다.
허용 응답 계약은 합성 활성화 승인·보류·거절이지만 실제 응답 수신은 후속 격리계층의
책임이다. 후보 코드·patch·diff를 포함하지 않으며 파일 변경, 활성화, rollback 실행,
결제·정산, 외부 차단조건 종료, `main` 병합 또는 배포를 수행하지 않는다.

## 실패 폐쇄

출처 대장 변조, digest 불일치, 미심사·보류·거절 출처, 만료, 순진입력, 거버넌스
변경, 중복 ID 충돌은 모두 거부한다. 동일 출처의 동시 생성은 하나의 패킷으로 수렴하고
생성 중 출처 대장이 바뀌면 새 패킷을 폐기한다.

## 최대 상태

`AWAITING_SYNTHETIC_LIMITED_PROMOTION_ACTIVATION_OPERATOR_DECISION`

이 상태는 운영자 결정·합성 활성화·운영승격을 의미하지 않는다.
