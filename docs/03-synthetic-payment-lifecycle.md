# 합성 Payment Intent 생명주기

## 상태

`CREATED → SYNTHETIC_AUTHORIZED → SYNTHETIC_CAPTURED → PARTIALLY_REFUNDED → REFUNDED`

매입 전에는 `CREATED` 또는 `SYNTHETIC_AUTHORIZED`에서 `CANCELLED`로 전환할 수 있다.
부분매입은 이 단계에서 허용하지 않으며, 매입 후 취소 대신 합성 환불만 허용한다.

## 불변식

- 모든 Intent·가맹점·고객·멱등 키는 `synthetic:` 식별자만 허용한다.
- 명령마다 현재 버전을 요구하여 뒤늦게 도착한 변경을 차단한다.
- 같은 멱등 키와 같은 명령은 기존 결과를 반환한다.
- 같은 멱등 키로 다른 금액·버전·명령을 제출하면 차단한다.
- 매입과 환불은 균형 분개가 성공한 뒤에만 상태를 갱신한다.
- 누적 환불액은 매입액을 초과할 수 없다.
- 사건은 이전 사건 다이제스트를 포함하는 append-only SHA-256 사슬로 고정한다.

## 의도적으로 없는 기능

- 카드번호·계좌번호·본인인증·실회원 필드
- 외부 PG·카드사·은행 Adapter와 Endpoint
- 운영 키·토큰·인증서 입력
- 실제 승인·매입·취소·환불·송금·정산 실행
- 자동 재시도에 의한 금액 변경
- ARKAON의 수수료·환불·분쟁정책 결정

CI 통과는 합성 상태기계의 불변식 증거일 뿐 운영결제 승인이 아니다.
