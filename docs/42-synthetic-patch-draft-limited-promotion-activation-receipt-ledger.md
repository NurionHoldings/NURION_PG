# 기능 #042 — 합성 제한승격 활성화 의사 수신대장

## 목적

기능 #041에서 검증된 합성 활성화 의사를 재시작 가능한 SQLite 증거로 보존한다.
이 대장은 운영자의 실제 승인이나 활성화 결과를 기록하지 않으며, 검증 결과와
운영행위를 분리하기 위한 격리 수신계층이다.

## 저장 범위

- 평가·봉투·nonce·패킷·Manifest·운영자 식별자·응답 유형을 다이제스트로 결합한다.
- 검증된 평가 전체를 정규 JSON으로 보존하고 재조회 시 다시 구성·검증한다.
- 수신증과 감사행은 단일 SQLite 트랜잭션으로 기록한다.
- 같은 평가의 정확한 재전송만 멱등 처리한다.
- 재시작 후에도 메타데이터·감사사슬·저장행 결합을 모두 재검증한다.

## 권한 경계

`AUTHORIZE_SYNTHETIC_LIMITED_PROMOTION_ACTIVATION` 수신증도 실제 운영자 결정이나
합성 활성화를 의미하지 않는다. 패킷 상태 변경, 코드·파일 변경, rollback 실행,
결제·정산, 외부 차단조건 종료, `main` 병합·배포·운영승격 메서드는 없다.

## 실패 폐쇄

순진입력, 운영 DB URI, 평가사슬 변조, 저장 JSON·열·감사행 불일치, 중복키 충돌,
수신증보다 늦은 평가, 트랜잭션 일부 실패는 모두 거부하거나 전체 rollback한다.

## 최대 상태

`SYNTHETIC_PATCH_DRAFT_LIMITED_PROMOTION_ACTIVATION_RECEIPT_RECORDED`

이는 검증된 합성 의사 증거가 보존되었다는 뜻일 뿐 승인·활성화 상태가 아니다.
