# 기능 #035 — Patch Draft 제한승격 운영자 재확인 패킷

## 목적

기능 #034에서 에테르니언 재심사를 통과한 합성 제한승격 Shadow 결과와 현재
거버넌스 차단조건을 하나의 불변 패킷으로 묶는다. 운영자가 같은 평가군·관찰창·
rollback 조건을 다시 확인할 수 있도록 하는 검토자료이며 승인이나 활성화가 아니다.

## 입력과 고정 범위

- 입력 상태는
  `READY_FOR_PATCH_DRAFT_LIMITED_PROMOTION_OPERATOR_RECONFIRMATION`만 허용한다.
- 계획·계획심사·후보·평가군·Shadow·에테르니언 재심사 다이제스트를 고정한다.
- 합성 표본 수, 관찰창, 각 관찰결과 다이제스트를 그대로 보존한다.
- `ROLLBACK_REQUIRED_CONFIRMED`, `HELD`, `REJECTED` 결과는 패킷 생성 대상이 아니다.
- 패킷 유효기간은 생성 시점부터 24시간이며 자동 갱신하지 않는다.

## 권한 경계

ARKAON은 패킷을 만들 수 있지만 운영자 재확인을 기록하거나 추정하지 않는다.
허용 응답은 재확인·보류·거절의 계약만 제시하며 실제 응답 수신은 후속 격리계층의
책임이다. 패킷은 후보 코드·patch·diff를 포함하지 않으며 파일 변경, 활성화,
rollback 실행, 결제·정산, 외부 차단조건 종료, `main` 병합 또는 배포를 수행하지 않는다.

## 실패 폐쇄

출처 대장 변조, digest 불일치, rollback 결과, 만료, 순진입력, 거버넌스 변경,
중복 ID 충돌은 모두 거부한다. 동일한 출처와 거버넌스의 동시 생성은 하나의 패킷으로
수렴하며 생성 중 출처 대장이 바뀌면 생성 결과를 폐기한다.

## 최대 상태

`AWAITING_PATCH_DRAFT_LIMITED_PROMOTION_OPERATOR_RECONFIRMATION`

이 상태는 운영자 결정·제한승격·운영승격을 의미하지 않는다.
