# 기능 #057 — 합성 fixture 물질화 Dry-run 내용 없는 scenario 초안

기능 #056의 독립심사를 통과한 계획에서 계보·contract·rollback digest와 미실행
scenario descriptor만 고정한다. 관찰값·fixture 내용·bytes·경로·파일은 포함하지 않는다.

최대 상태는 `SYNTHETIC_FIXTURE_MATERIALIZATION_DRY_RUN_SCENARIO_DRAFTED`이며 별도 심사를
요구한다. Fixture 물질화·filesystem 기록·Dry-run·활성화·rollback·결제·외부 API·병합·배포를 수행하지 않는다.
