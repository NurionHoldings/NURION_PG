# 기능 #041 — 합성 제한승격 활성화 운영자 의사 검증

## 목적

기능 #040의 운영자 판단 패킷을 대상으로 서명된 합성 의사 봉투의 형식·진위·
유효기간·nonce를 검증한다. ARKAON은 운영자의 의사를 만들거나 서명하지 않으며,
검증 성공도 운영자 결정 기록이나 활성화를 의미하지 않는다.

## 검증 계약

- 합성 운영자 식별자와 사전 등록된 합성 검증키만 허용한다.
- HMAC-SHA256 합성 서명, 10분 유효기간, 최대 30초 미래 시각 오차를 검사한다.
- 패킷 ID·digest·범위·필수 확인문·허용된 응답을 정확히 결합한다.
- 응답 계약은 합성 활성화 승인·보류·거절을 구분한다.
- 같은 봉투의 정확한 재전송만 멱등 처리하고 nonce 재사용은 거부한다.

## 권한 경계

이 계층은 서명 생성, 실제 본인인증, 운영자 결정 영속 기록, 패킷 상태 변경,
합성 활성화 또는 rollback 실행을 하지 않는다. 코드·patch·diff·파일 변경,
결제·정산, 외부 차단조건 종료, `main` 병합·배포·운영승격 기능도 없다.

## 실패 폐쇄

위조 서명, 미등록·철회·기간 외 키, 만료·미래 봉투, 패킷 불일치, 순진입력,
중복 envelope ID 충돌, nonce 재전송, 기존 평가사슬 변조는 모두 거부한다.

## 최대 상태

`SYNTHETIC_PATCH_DRAFT_LIMITED_PROMOTION_ACTIVATION_INTENT_VALIDATED`

검증 결과는 후속 격리 수신대장에 전달할 수 있는 합성 증거일 뿐 승인 기록이 아니다.
