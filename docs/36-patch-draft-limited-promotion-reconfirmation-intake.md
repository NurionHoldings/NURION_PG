# 기능 #036 — Patch Draft 제한승격 운영자 재확인 의사 검증

기능 #035의 운영자 재확인 패킷을 대상으로 서명된 합성 의사 봉투의 형식과
진위만 검증한다. 운영자 의사를 생성·서명·영속 기록하거나 실제 제한승격을
활성화하지 않는다.

## 봉투 계약

- 합성 운영자 ID `synthetic:operator:CHOI_IN_SEOK`
- 현재 재확인 패킷 ID와 SHA-256
- 패킷에 고정된 합성 전용 범위·선택지·필수 확인사항
- 발행시각, 10분 만료시각, 일회성 nonce
- 합성 검증키 ID와 HMAC-SHA256 서명

검증 대상 선택지는 재확인·보류·거절뿐이다. 실제 인증서·비밀번호·운영 토큰·
개인정보는 받지 않으며 이 기능에는 서명 생성 메서드가 없다.

## 실패 폐쇄

- 봉투 만료, 패킷 만료, 30초 초과 미래시각을 거부한다.
- 패킷 ID·다이제스트·범위·선택지·확인사항 불일치를 거부한다.
- 미등록·만료·철회·위변조 키와 잘못된 HMAC을 거부한다.
- 동일 봉투의 정확한 재전송만 멱등 처리하고 payload 충돌을 차단한다.
- 다른 봉투의 nonce 재사용과 nonce 색인·평가 사슬 위변조를 차단한다.
- 검증 전후 재확인 패킷의 상태와 증거는 변경하지 않는다.

## 권한 경계

최대 상태는
`SYNTHETIC_PATCH_DRAFT_LIMITED_PROMOTION_RECONFIRMATION_VALIDATED`다. 이는 합성
계약검증 결과일 뿐 법적·운영상 재확인 기록이 아니다. 코드·patch·diff 생성,
파일 변경, 제한승격·rollback 실행, 결제·송금, 병합·배포·운영 활성화 기능은 없다.
