# 기능 #038 — 합성 제한승격 활성화 사전점검 Manifest

기능 #037의 합성 재확인 수신증과 기능 #035의 현재 재확인 패킷을 다시 결합해
에테르니언 최종심사용 활성화 사전점검 메타데이터를 작성한다. 이 Manifest는 실제
운영자 재확인이나 활성화 명령이 아니다.

## 고정 계보

- 재확인 수신증·평가·봉투·패킷·Shadow·계획 ID와 SHA-256
- 후보·평가군 다이제스트, 합성 표본 수, 관찰창
- 모든 관찰결과 다이제스트와 네 가지 rollback 트리거
- 현재 차단조건의 거버넌스 다이제스트

`RECONFIRM_SYNTHETIC_PATCH_DRAFT_LIMITED_PROMOTION` 합성 수신증만 허용한다.
보류·거절은 Manifest를 만들 수 없으며, 만료된 패킷도 거부한다.

## 실패 폐쇄

- 수신대장의 메타데이터·감사사슬·저장 결합을 재검증한다.
- 재확인 패킷 사슬과 수신증의 패킷·Shadow 결합을 재검증한다.
- 같은 수신증의 정확한 재전송만 멱등 처리한다.
- 출처·계보·계획·Shadow·거버넌스가 달라지면 충돌로 차단한다.
- Manifest 작성 전후 두 출처의 증거 다이제스트가 달라지면 결과를 폐기한다.

## 권한 경계

최대 상태는 `SYNTHETIC_LIMITED_PROMOTION_ACTIVATION_MANIFEST_DRAFTED`다.
에테르니언 최종심사 전에는 합성 활성화도 허용하지 않는다. Manifest에는 코드·
patch·diff나 실행 명령이 없으며 활성화, rollback 실행, 파일 변경, 결제·정산,
외부 차단조건 종료, 병합·배포 또는 운영 승격 메서드가 없다.
