# 기능 #044 — 합성 활성화 초안 독립심사 대장

기능 #043의 메타데이터 초안을 에테르니언 독립심사 대상으로 제출하고 `PASS`, `HOLD`,
`REJECT` 결과를 위변조 탐지 사슬에 고정한다. 운영자 활성화 의사와 심사 판단은 분리된다.

`PASS`의 최대 상태는 `READY_FOR_SYNTHETIC_ACTIVATION_DRY_RUN_DESIGN`이다. 이는 후속
합성 Dry-run 설계를 검토할 수 있다는 뜻일 뿐, Dry-run 실행이나 활성화 승인이 아니다.
`HOLD`와 `REJECT`는 준비 출처가 될 수 없으며 심사 결과는 변경할 수 없다.

실제 활성화·rollback·결제·정산·송금·외부 API·병합·배포 메서드는 제공하지 않는다.
